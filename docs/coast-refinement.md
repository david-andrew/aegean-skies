# Sub-source coast refinement

The erosion/source assets and the canonical 14 m vertices remain unchanged.
Coastal contact and near rendering now subdivide those triangles down to
14/64 = 0.21875 m. `coast_field.jo` is the authority for the added relief;
`surface_height`, `new_land_surface` and `world_source_surface` use its fixed
finest triangulation, independently of the camera, quality tier and cache.
`height` and `world_source_sample` remain source/ecology queries. Existing
walking/landing uses `surface_height`; vessel clearance uses `place_ground`,
which selects one of the refined contact queries.

Five deterministic bands have 7, 3.5, 1.75, 0.875 and 0.4375 m spacing. Their
vertical contribution is bounded by 1.01 m. Two related fields perturb the
local contour by at most 1.15 m horizontally, expressed through the canonical
cell's gradient. That term has a smooth zero window at cell boundaries, where
the base gradient can change; the smaller vertical relief continues across
them. Canonical corners never move. Relief fades out between -3 and -10 m
underwater and between 64 and 192 m above water, including low cliff faces.
This remains a heightfield: no overhangs or separate decorative collision rocks.

The bands are generated by game code into a 512² RGBA8 pattern (1 MiB each on
CPU and GPU). Three channels contain the vertical and two contour fields. Their
112 m microdetail period does not repeat the underlying terrain/coast. CPU and
GPU manually interpolate the same quantized bytes. There are no downloaded or
generated-art assets, and no country-wide fine bake. `coast_pattern.jo` owns
the generator; changing its constants changes contact geometry.

`coast_mesh.jo` instances seven shared grids over existing canonical cells.
Projected cell size selects a continuous subdivision level, using the viewport
and FOV and the existing terrain quality budget. Cells within approximately
25 m of contact use the finest grid on every tier. Adjacent cells share the
less detailed edge state; dyadic b-c triangulation makes both sides coincide
through morphs. Canonical patches/tile atlases stay resident; there are no new
per-frame mesh allocations or GPU geometry uploads. Instance lists are rebuilt
for the nearby replaced patches. The effective focal length is capped at 1200
pixels (621 m maximum refinement radius), bounding work under extreme zoom;
this cap takes priority over additional zoom detail. Distant terrain uses the
original draw path and adds no detail triangles.

The sea reconstructs the same morphed triangles, including constrained boundary
strips, before choosing foam, sand transparency and shallow-water color. Legacy
coasts reuse the existing signed 24-bit height atlas. New land streams a 65²
canonical-height atlas over 896 m, four rows per frame, publishing all 17 frames
of work atomically. Until a new map is ready, the previous valid map and existing
coarse depth fallback remain available. Streaming terrain likewise retains its
existing coarse fallback until contact tiles are ready. Neither fallback is a
collision authority. Depth decoding keeps dry heights signed until after
interpolation, avoiding broad false foam bands caused by clamping dry texels.

Validation tools:

- `sloppy test tests/coast_test.jo --release`: fixed vertices, contact triangles,
  mixed edges, projection selection, sub-source bands, cached/pure agreement.
- `SLOPPY_SOFTWARE=1 sloppy --release tools/coast_check.jo`: CPU/texture parity,
  sea/mesh morph and edge parity, atomic bounded new-depth publication.
- `tools/coast_capture.jo`: deterministic `COAST_SITE=legacy|new|beach|harbor`,
  `COAST_RANGE=2000|300|50|2`; the beach's 2 m recipe stands on land.
- `AEGEAN_COAST=0`: diagnostic rendering baseline only. Physics remains refined;
  this is not a gameplay setting or a second terrain authority.

Run all tools headlessly and silently with `SLOPPY_THREADS=1`. Captures and
machine-specific measurements belong in scratch, not the asset directory.
